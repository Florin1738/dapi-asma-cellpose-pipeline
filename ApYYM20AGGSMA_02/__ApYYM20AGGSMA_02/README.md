# Download Error Sidecar Folder

This folder is not image data.

It contains per-position `_H##_Error.txt` files created during a failed or partial download. The top-level `___All_Errors.txt` reports `WebMeTAException` errors and a timestamp of `06/22/2026 19:40:58 UTC`.

Do not use this folder as pipeline input.

If raw Keyence data or metadata are needed, re-download or re-export from the original source rather than analyzing these error sidecars.
