# `ApYYM20AGGSMA_02`

This local folder contains exported microscopy data and download sidecars.

Use the nested image folder for the current TIFF exports:

```text

```

Specifically:

```text

```

See the tracked project document for the full inventory and caveats:

```text
docs/DATA_ORGANIZATION.md
```
