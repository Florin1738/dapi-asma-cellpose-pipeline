# Methodology Run Logs

Every new method decision, threshold change, segmentation experiment, or
source-backed scientific assumption must be logged here.

Use the template:

```text
docs/methodology/RUN_LOG_TEMPLATE.md
```

Naming convention:

```text
YYYY-MM-DD-short-topic.md
```

Required statuses:

- `accepted`: method is part of the current workflow
- `exploratory`: useful for diagnosis or comparison, not a default endpoint
- `rejected`: tested or considered and not suitable as a current endpoint
- `superseded`: replaced by a newer method
