# Documentation Index

This folder contains project documentation, methodology records, output contracts, and run logs.

## Current Methodology

- `methodology/CURRENT_METHODS.md`: current scientific status of the image-analysis methods.
- `methodology/THRESHOLDS_AND_PARAMETERS.md`: parameter, threshold, and decision ledger.
- `methodology/SOURCES.md`: methodology sources collected during setup.
- `methodology/run_logs/`: chronological run logs for analyses and tooling changes.

## Contracts and Setup

- `OUTPUT_CONTRACT.md`: stable output column names and artifact expectations.
- `IMAGE_INPUTS.md`: channel and image input assumptions.
- `INSTALLATION.md`: environment setup notes.
- `RELEASE_PACKAGING.md`: maintainer steps for GitHub release zips.
- `VALIDATION.md`: validation strategy and metric definitions.
- `QC_AND_VISUALIZATION.md`: expected QC visuals.

## Project Navigation

- `DATA_ORGANIZATION.md`: microscopy data layout and local/private data policy.
- `methodology/README.md`: how methodology records and run logs should be maintained.
- `methodology/CURRENT_METHODS.md`: current method status.
- `methodology/THRESHOLDS_AND_PARAMETERS.md`: current parameter and threshold registry.

Older exploratory notes may exist in local working folders. Do not treat every local note as the current recommended method; use the current-methods and threshold files first.
